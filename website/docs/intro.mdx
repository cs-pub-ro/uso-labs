# Utilizarea Sistemelor de Operare

Bine ai venit pe pagina laboratoarelor de **USO**.

Aici înveți să folosești Linux eficient: linia de comandă, sistemul de fișiere, procese, utilizatori, rețelistică și automatizarea sarcinilor cu scripturi shell.

## Cum folosești site-ul

- Fiecare laborator are propria pagină, cu noțiuni teoretice și exerciții practice.
- Parcurge laboratoarele în ordine, pentru că fiecare se bazează pe cele anterioare.
- Rulează comenzile pe măsură ce citești. USO se învață exersând, nu doar citind.
